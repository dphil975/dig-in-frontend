## 🛠️ HOW TO EXPAND THE DATABASE SYSTEMATICALLY

### Automatic Expansion Pattern

Each new country needs this exact JSON structure:

```json
{
  "country": "Country Name",
  "region": "Continent/Region",
  "breakfast": [
    {
      "id": "code-category-name",
      "name": "Dish Name (English) / Local Name",
      "difficulty": "Easy|Medium|Hard",
      "servings": 4,
      "prepTime": minutes,
      "cookTime": minutes,
      "description": "Brief description of dish",
      "seasonings": ["seasoning1", "seasoning2", "seasoning3"],
      "ingredients": [
        "ingredient with measurement",
        "ingredient with measurement"
      ],
      "instructions": [
        "Step 1",
        "Step 2",
        "Step 3"
      ],
      "notes": "Preparation tips",
      "fun_fact": "Cultural or historical fact",
      "alternatives": [
        "Alternative ingredient substitution",
        "Another variation"
      ]
    }
  ],
  "lunch": [],
  "dinner": [],
  "snacks": [],
  "desserts": [],
  "nonAlcoholicDrinks": [],
  "alcoholicDrinks": []
}
```

### Research Sources for Authentic Recipes

For each country, research from:
1. **Official tourism/cultural websites** - Often have cuisine sections
2. **Celebrity chefs from that country** - YouTube channels, cookbooks
3. **Wikipedia culinary sections** - Lists of typical dishes
4. **Food blogs from native cooks** - Authentic perspectives
5. **Cookbook databases** - Published traditional recipes
6. **Academic culinary anthropology papers** - Historical accuracy
7. **Street food documentaries** - Real preparation methods
8. **Regional restaurant menus** - Professional standards

### Quality Checklist for Each Recipe

Before saving a recipe, verify:
- [ ] Name is in local language + English translation
- [ ] Description explains cultural/regional significance
- [ ] Seasonings list is complete and specific
- [ ] Ingredients have measurements (not "some flour")
- [ ] Instructions are 8-15 clear steps
- [ ] Cooking times are realistic
- [ ] Fun fact is genuine and interesting
- [ ] Difficulty is accurate (Easy = <30 min, Medium = 30-60 min, Hard = 60+ min)
- [ ] 2+ alternatives provided
- [ ] No generic/placeholder text
